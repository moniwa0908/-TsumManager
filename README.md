# TsumManager 7.3 Plus & Rewards

指定されたプレミアムツム一覧の「ミッキー＋」から「ガジェット」までを対象に、
各個別ページのスキル上げ必要数を反映したバージョンです。

## 対象範囲

- プレミアムBOX＋：ミッキー＋〜ジェシー＋
- アイテムストア限定：スポーティーマックス
- ピックアップ限定：アーロ〜ストームトルーパー
- イベント報酬：アブー〜おしりまんまるプー＋
- ログイン報酬：スフレ、コグスワース
- 友達招待・ビンゴ報酬：オズワルド、リトルグリーンメン
- ぬりえミッション報酬：ガジェット

## 更新結果

- 対象反映：68体
- 新規追加：2体
- 収録ツム数：754体
- 「スキル3/6 25%」形式の入力・表示を維持
- 過去の画像・所持数・お気に入り・メモを探す復旧機能を維持
- 新しい大容量保存キーを増やさない安全設計

## スポーティーマックスについて

個別ページでは、スキル1→2が1体であることのみ確認できます。
スキル2→3以降とスキルマ合計は記事上で未掲載のため、アプリでは暫定的に各段階1体としています。
このツムだけは「確認済み」ではなく暫定データとして扱います。

## 特殊例

- おしりまんまるプー＋：合計8体、1・1・1・2・2
- ガジェット：合計3体、1・1
- ピート：合計30体、2・3・6・8・10
- スクルージ：合計15体、2・3・3・3・3
- うさぎどん、サンタジャック：1体でスキルMAX
