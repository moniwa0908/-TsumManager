# TsumManager 8.3.5 MAX & Sally Fix

## MAXボタン
一覧の各ツムの「−」「＋」の横へMAXボタンを追加しました。
押すと、そのツムの所持数がスキルマ必要数になります。
誤って押した場合は操作取り消しが利用できます。

## サリー（ナイトメア）
- スキルマ必要数：32体
- 入手：1体
- スキル1→2：2体
- スキル2→3：3体
- スキル3→4：4体
- スキル4→5：6体
- スキル5→6：16体
- skillGrowth：[2,3,4,6,16]

2体所持の場合は「スキル2/6 33%」と表示されます。

## スキル進捗計算
スキルマ32体・36体のツムは、登録済みのskillGrowthの合計がrequiredと一致する場合、
均等配分ではなくskillGrowthを使って進捗を計算します。
