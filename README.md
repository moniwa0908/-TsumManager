# TsumManager 8.4.26 Full Backup Image Restore Fix

## 原因
完全バックアップ読込時に `mergeMaster()` が画像を除外した後、
`replaceAllStoredImages(tsums)` がIndexedDBを一旦全消去していたため、
バックアップ読込で画像が消えることがありました。

## 修正
- 書き出し時にIndexedDBから全画像を取得してバックアップへ確実に含める
- 復元時にバックアップ画像をmergeMaster後のツムへID優先で再結合
- 画像入りバックアップならIndexedDBへ復元
- 画像0件の古い/不完全バックアップなら現在の画像を消さず保持
- 復元後にIndexedDBから再読込して図鑑・一覧へ反映

## 注意
8.4.25以前に作成したJSONで「画像：0体」と表示されるものには画像データがありません。
その場合でも8.4.26では現在端末に残っている画像を消しません。
新しい完全バックアップは8.4.26で作り直してください。
