# TsumManager Ver.7

Ver.6までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## Ver.7の追加機能

- ツム詳細画面
- 詳細画面から所持数を直接入力
- 詳細画面からお気に入り切替
- 残り5体以内のツムを強調表示
- 「画像なし」絞り込み
- データ診断
- 重複名、必要数異常、所持数超過などの確認
- Ver.1〜Ver.6の保存データを自動引継ぎ
- 646体のマスターデータを維持
- 既存の画像管理、BOX入力、スキルチケット入力、分析、バックアップを維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
