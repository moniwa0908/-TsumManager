# TsumManager 8.0 Safe Storage

アプリの更新データと個人の入力データを完全に分離した安全保存版です。

## 新しい保存設計

### マスターデータ
アプリファイル内で管理します。

- ツム名
- カテゴリ
- スキルマ必要数
- スキル成長表
- 登場年月
- シリーズ

### ユーザーデータ
バージョン番号を付けない固定の保存領域で管理します。

- 所持数（5/36など）
- スキル進捗
- お気に入り
- メモ
- タグ
- 各種評価
- 育成優先度

### 画像
IndexedDBという画像向けの保存領域で管理します。

- 通常のLocalStorageより容量に余裕がある
- アプリのバージョンを変えても同じ保存場所を使用
- マスターデータの更新から独立

## 旧データの自動移行

初回起動時に、Ver.1〜Ver.7.3までの保存データを検索します。

1. 入力内容が最も多い旧データを選択
2. 所持数・メモなどを固定ユーザー領域へ移行
3. 画像をIndexedDBへ移行
4. 移行成功後、容量を圧迫していた旧結合データを削除

## バックアップの違い

### 軽量バックアップ（画像なし）

- 所持数
- スキル進捗
- お気に入り
- メモ
- タグ
- 目標・履歴

画像を含まないためファイルが小さく、日常的な保存向けです。

### 完全バックアップ（画像込み）

軽量バックアップの内容に加えて、登録画像も保存します。
機種変更、Safariデータ消去、故障への備えはこちらを使用してください。

## 今後のアップデート

今後はアプリのマスターデータだけを更新します。
固定ユーザーデータとIndexedDB画像には触れないため、通常のGitHub更新で所持数や画像が初期化されない設計です。

## 注意

Safariの「履歴とWebサイトデータを消去」を行うと、ブラウザ内のユーザーデータが削除される場合があります。
定期的に完全バックアップをiCloud Driveへ保存してください。

- tsums-data.js
