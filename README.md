# TsumManager 8.1 UI

設定画面を整理し、普段使いで分かりやすい項目だけを残したUI改善版です。

## 削除した項目

- 操作取り消し履歴
- 一覧をコンパクト表示

操作取り消し履歴の内部データは互換性のため残していますが、設定画面には表示しません。

## 新しい表示設定

### 文字サイズ

- 小さめ
- 標準
- 大きめ

一覧のツム名、スキル表示、補足情報の文字サイズが明確に変わります。

### ツム画像サイズ

- 小さめ
- 標準
- 大きめ

一覧カードの画像サイズが明確に変わります。

## 設定画面の整理

上部に次の項目をまとめています。

1. 安全保存システム
2. 完全バックアップ（画像込み）
3. 軽量バックアップ（画像なし）
4. 表示設定
5. アプリ情報

## 保存について

Ver.8.0で導入した安全保存設計を維持しています。

- 所持数・スキル進捗・メモは固定保存領域
- 画像はIndexedDB
- アップデートではマスターデータだけ更新
- 文字・画像サイズの設定も固定保存領域へ保存

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubへ上書きしてCommit changesを押してください。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md
