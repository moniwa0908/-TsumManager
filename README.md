# TsumManager 1.2

TsumManager 1.1までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 1.2の追加機能

- 図鑑を60体ずつ段階表示してスクロールを軽量化
- スキルマ目前ランキング
- 必要コイン上位ランキング
- CSV書き出し
- CSV読み込み
- Excelなどで所持数・必要数・タグ・メモを編集可能
- ページ上部へ戻るボタン
- Ver.1〜TsumManager 1.1のデータを自動引継ぎ
- 今日の育成、取り消し、履歴復元、図鑑、ガチャ計画を維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
