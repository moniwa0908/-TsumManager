# TsumManager Ver.3

iPhone向けのツムツム・スキルマ管理Webアプリです。

## 収録
- 初期収録：646体
- ハピネス：14体
- プレミアム：148体
- 期間限定：484体

## 主な機能
- Ver.1／Ver.2の保存データを自動移行
- 検索、カテゴリ・状態絞り込み、並べ替え
- ＋1／＋5切替
- お気に入り、画像登録、メモ
- カテゴリ別分析
- JSONファイルでバックアップ・復元
- PWA・オフライン対応
- ダークモード

## 更新方法
ZIPを展開し、中の全ファイルをGitHubリポジトリ直下へアップロードして上書きします。
その後 `Commit changes` を押してください。
