# TsumManager 8.4.52 Ten Pull Image Reader

## 追加
- 入力タブに「📷 10連結果読み取り」を追加
- 「BOX購入結果」スクリーンショットの4+4+2配置から10枠を自動切り出し
- Safari内に登録済みのツム画像とブラウザ内で照合
- 各枠に自動候補を表示
- 誤判定はプルダウンから修正可能
- 確認後、「この10体を一括反映」で所持数へ加算
- 同じツムが複数回出た場合は自動で＋2、＋3としてまとめて反映
- 反映前には必ずユーザーが10枠を確認できる安全設計

## 注意
画像認識は端末内の登録済みツム画像との類似比較です。
完全自動確定ではなく「自動候補＋確認」を前提にしています。
