# TsumManager 6.0.2

画像ファイル名がツム名と完全一致しない場合に、近い名前の候補から選択して登録できる修正版です。

## 6.0.2の画像一括登録

1. 完全一致した画像は自動登録
2. 完全一致しない画像は自動登録しない
3. 画像未登録のツムから近い名前を最大8件表示
4. 正しいツムを選択
5. 「選択した候補へ反映」を押して登録

これにより、「クリストファー・ロビン」の画像を候補から正しく選択して登録できます。

## 安全対策

- 似た名前だけでは自動登録しません
- 画像登録済みツムは候補から除外します
- 同じツムへ重ねて登録しません
- 「登録しない」も選択できます
- Ver.1〜TsumManager 6.0.1の保存データを自動引継ぎ

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
