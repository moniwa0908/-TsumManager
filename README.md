# TsumManager Ver.9

Ver.8までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## Ver.9の追加機能

- 各ツムへ自由タグを登録
- タグによる一覧絞り込み
- タグ名も検索対象
- タグ別コレクション率
- スキルチケット配分シミュレーター
- 少ない枚数でスキルマにできる候補を自動提案
- シミュレーターは実データを変更せず計算のみ
- Ver.1〜Ver.8の保存データを自動引継ぎ
- 646体のマスターデータを維持
- ギャラリー、詳細、画像管理、BOX入力、分析、バックアップを維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
