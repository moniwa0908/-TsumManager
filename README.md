# TsumManager 6.3.5 Rescue

保存データが消えたように見え、アプリが反応しなくなった場合の緊急復旧版です。

## 原因

バージョンごとに画像入りデータを別のLocalStorageキーへ複製していたため、Safariの容量上限を超え、起動時の保存処理でJavaScriptが停止する可能性がありました。

## 復旧方法

- 過去の全保存キーを確認
- 画像数・所持数・お気に入り・メモなどが最も多いデータを自動選択
- 新しい保存キーを増やさず、Ver.6.3.3の保存領域を継続使用
- 起動直後の強制保存を廃止
- 容量不足時もアプリ全体が停止しないよう修正
- 設定画面に復旧元・画像数・所持数合計を表示
- 復旧データを書き出すボタンを追加

## 重要

Safariの「履歴とWebサイトデータを消去」は行わないでください。
旧データが残っていれば、本版で復旧できる可能性があります。
