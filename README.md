# TsumManager 2.0

TsumManager 1.2までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 2.0の追加機能

- 育成アシスタント
- 今日の育成、育成予定、残り数、スキルチケット在庫から候補を提案
- 育成目標の作成・編集・削除
- スキルマまたは指定所持数を目標に設定
- 目標期限と残り日数
- スキルチケット在庫管理
- 目標達成に必要な枚数と不足数を計算
- 現在の在庫で達成可能な目標を表示
- 目標・在庫もバックアップ対象
- Ver.1〜TsumManager 1.2の保存データを自動引継ぎ
- 646体図鑑、BOX入力、ガチャ計画、CSV、履歴復元、画像管理を維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
