# TsumManager 6.3.4

画像一括登録後に成功件数などが表示されない問題を修正したバージョンです。

## 修正内容

- 画像一括登録中に「何件目を処理中か」を表示
- 完全一致で登録した件数を逐次表示
- 候補選択待ち件数を表示
- Safariの保存容量不足を検出
- 容量不足時に無反応にならず、理由と登録済み件数を表示
- 容量不足になった画像は登録前の状態へ戻して安全に停止
- 画像を360pxから240pxへ軽量化
- JPEG品質を調整し、保存容量を削減
- 候補から反映する処理にも容量不足対策を追加
- 推定保存使用量を結果欄に表示
- Ver.6.3.3までの751体データと保存内容を引継ぎ

## 注意

画像はSafariのブラウザ保存領域を使用します。多数登録すると容量上限に達することがあります。
定期的に画像込みバックアップを作成してください。

## GitHubへの更新方法

ZIPを展開し、8ファイルをGitHubへ上書きしてCommit changesを押してください。
