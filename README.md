# TsumManager 8.3.1 Name Match Fix

画像一括登録で「ベイマックス2.0」が完全一致にならない問題を修正したバージョンです。

## 原因

以前の処理は、ツム名にも「最後のピリオド以降を拡張子として削除する処理」を使用していました。

- 画像ファイル名：`ベイマックス2.0.jpeg` → `ベイマックス2.0`
- アプリのツム名：`ベイマックス2.0` → `ベイマックス2`

となり、完全一致しませんでした。

## 修正内容

- 画像ファイル名とツム名の正規化処理を分離
- jpg、jpeg、png、webp、gif、heicなどの実在する画像拡張子だけを削除
- ツム名の `.0` は削除しない
- 完全一致判定ではツム名専用の正規化処理を使用
- 候補検索でも同じツム名専用処理を使用

## 修正後

`ベイマックス2.0.jpeg` と `ベイマックス2.0` は完全一致し、候補選択を通らず自動登録されます。

所持数、画像保存、IndexedDB、バックアップなどの機能には変更を加えていません。
