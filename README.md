# TsumManager 6.2

画像を含む完全バックアップ・復元に対応した安全性強化版です。

## 6.2の追加機能

- 所持数・画像・お気に入り・メモ・タグ・評価を完全バックアップ
- 育成目標・今日のタスク・ガチャ計画・進捗記録も保存
- 1つのJSONファイルとして書き出し
- バックアップファイルから全データを復元
- 読込前に現在データを自動バックアップ
- 更新前クイックバックアップ
- 最終バックアップ日時とファイルサイズを表示
- 画像登録数と保存容量の目安を表示
- バックアップファイルの内容確認後に復元
- Ver.1〜TsumManager 6.1.1の保存データを自動引継ぎ

## 更新前に行うこと

1. アプリの「設定」を開く
2. 「完全バックアップ」を開く
3. 「更新前クイックバックアップ」を押す
4. ダウンロードされたJSONファイルをiCloud Driveなどへ保存
5. その後GitHubを更新

## 注意

Safariの「履歴とWebサイトデータを消去」や、iPhoneの容量不足によって、ブラウザ内の画像が失われる可能性があります。
定期的に画像込みバックアップを保存してください。

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
