# TsumManager 3.0

TsumManager 2.0までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 3.0の追加機能

- 現在の進捗をスナップショットとして記録
- 前回比とスキルマ増加数
- 直近12回の進捗を簡易グラフ表示
- 最新記録の削除・全記録削除
- コイン予算シミュレーター
- 現在コイン、1日獲得量、目標日から引けるBOX回数を計算
- 育成目標に途中目標を設定
- 進捗記録もバックアップ対象
- Ver.1〜TsumManager 2.0の保存データを自動引継ぎ
- 646体図鑑、育成アシスタント、目標、ガチャ計画、CSV、画像管理を維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
