# TsumManager 6.3

Game8の全ツム一覧とスキルマ必要数一覧をもとに、ツムデータを大幅更新したバージョンです。

## 更新内容

- 収録ツム数：751体
- 新規追加：104体
- Game8の必要数を確認して反映：527体
- 必要数が最新表に未掲載・未確認のツム：224体
- ハピネス、イベント、ビンゴ限定ツムの特殊な必要数を修正
- ラビットは3体、ピートは30体、ほねほねプルートは5体などを反映
- 既に登録した所持数、画像、お気に入り、メモ、タグ、評価は引継ぎ
- スキルマ必要数だけ新しいマスターデータを優先
- Ver.1〜TsumManager 6.2の保存データを自動引継ぎ

## 注意

Game8の「全ツム一覧」は2026年7月31日更新ですが、「スキルマ必要数一覧」は2025年11月20日更新です。
そのため、必要数表にまだ掲載されていない新しいツムは36体を暫定値としているものがあります。

## 更新前の推奨手順

1. 現在のアプリで「設定」を開く
2. 「更新前クイックバックアップ」を押す
3. JSONバックアップをiCloud Driveへ保存
4. ZIP内の8ファイルをGitHubへ上書き
5. Commit changesを押す
