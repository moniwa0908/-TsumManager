# TsumManager Ver.6

Ver.5の保存データを引き継ぐ、iPhone向けツム管理Webアプリです。

## Ver.6の追加機能

- ツム画像を正方形に自動トリミング
- 画像を自動圧縮してSafari内へ保存
- 登録画像の一覧管理
- 登録画像の個別削除
- 最近使ったツムをホーム画面に表示
- 最近使った履歴の削除
- BOX入力・スキルチケット入力を最近使ったツムへ反映
- バックアップに画像・履歴・最近使用情報を含める
- Ver.1〜Ver.5の保存データを自動引継ぎ
- 646体のマスターデータを維持
