# TsumManager Ver.5

iPhoneのSafari／GitHub Pagesで動く、個人用のツム管理Webアプリです。

## 主な機能

- Ver.1〜Ver.4の保存データを自動引継ぎ
- 646体のマスターデータ
- ホームダッシュボード
- ツム一覧、検索、絞り込み、並べ替え
- 所持数の＋1／＋5入力
- BOX結果の一括入力
- スキルチケット入力
- 入力履歴
- 育成優先度
- スキルマ目前・未所持のクイック表示
- ツム画像、メモ、お気に入り
- カテゴリ別分析と必要コイン内訳
- JSONバックアップ／復元
- ダークモード
- PWA・オフライン対応

## GitHubへの更新方法

ZIPを展開し、以下の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
