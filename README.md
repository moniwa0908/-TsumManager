# TsumManager 5.0

TsumManager 4.0までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 5.0の追加機能

- 今日のタスク
- タスクの完了チェックと進捗率
- 関連ツム・目標回数の登録
- 月次成長レポート
- 所持ツム増加、スキルマ増加、進捗増加、完了タスク数
- 連続操作の取り消し履歴
- 取り消し履歴から個別に復元
- 画像ビューア
- 登録画像の前後移動
- 画像タップで拡大表示
- タスク・取り消し履歴もバックアップ対象
- Ver.1〜TsumManager 4.0の保存データを自動引継ぎ
- 646体図鑑、攻略ランキング、BOX確率、育成目標、進捗記録、CSVを維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
