# TsumManager 1.0

Ver.9までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリの完成版基礎です。

## TsumManager 1.0の主な機能

- 646体のツム図鑑
- 所持・未所持・スキルマ・画像登録済みで図鑑絞り込み
- 図鑑からツム詳細画面を表示
- セレクトBOX・ピックアップ・プレミアムBOXの計画保存
- ガチャ対象ツムの残り必要数を自動計算
- ガチャ対象ツムの必要コインを自動計算
- 対象ツム名を貼り付ける簡易ガチャ計算
- ガチャ計画もバックアップ対象
- Ver.1〜Ver.9の保存データを自動引継ぎ
- 画像管理、タグ、ギャラリー、詳細、BOX入力、スキルチケット、育成シミュレーター、分析を維持
- PWA・オフライン対応

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
