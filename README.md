# TsumManager 6.0.1

TsumManager 6.0の画像一括登録で、似た名前の別ツムへ誤登録される問題を修正したバージョンです。

## 修正内容

- 画像一括登録は完全一致したツムだけ自動登録
- 空白や記号を除いた完全一致にも対応
- 部分一致では自動登録しない
- 似た名前は候補として表示するだけ
- 候補が複数ある場合も自動登録しない
- 「クリストファー・ロビン」が「クリストフ」に登録されるような誤一致を防止
- Ver.1〜TsumManager 6.0の保存データを自動引継ぎ

## 画像ファイル名

ツム名と同じファイル名にしてください。

- クリストファー・ロビン.jpg
- クリストフ.jpg

名前が完全一致しない画像は登録されず、結果欄に表示されます。

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
