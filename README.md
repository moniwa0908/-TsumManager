# TsumManager Ver.8

Ver.7までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## Ver.8の追加機能

- 画像中心のギャラリー表示
- 標準・コンパクト・ギャラリーの3表示
- ホーム画面におすすめ育成候補
- 所持数と残り数から育成候補を自動計算
- 複数ツムの所持数をまとめて直接入力
- 「ツム名,所持数」の形式で一括反映
- Ver.1〜Ver.7の保存データを自動引継ぎ
- 646体のマスターデータを維持
- 詳細画面、画像管理、BOX入力、スキルチケット、分析、バックアップを維持

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
