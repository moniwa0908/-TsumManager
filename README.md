# TsumManager 6.3.2

TsumManager 6.3.1でバックアップボタンが反応しなかった原因を修正したバージョンです。

## 原因

画面から削除された「BOX確率シミュレーター」のボタンをJavaScriptが探し、存在しない要素に処理を設定しようとして停止していました。
そのため、その後ろにあるバックアップボタンの処理が登録されていませんでした。

## 修正内容

- 存在しない確率シミュレーター要素でJavaScriptが停止しないよう修正
- 保存状態確認パネルがない場合も停止しないよう修正
- 更新前クイックバックアップ処理まで必ず読み込まれるよう修正
- iPhoneでは共有画面から「ファイルに保存」
- PCではJSONファイルをダウンロード
- バックアップボタン動作確認ボタンを追加
- Ver.6.3の751体データを維持
- Ver.6.3.1までの保存データを自動引継ぎ

## 確認方法

1. 設定を開く
2. 「バックアップボタン動作確認」を押す
3. 下の表示が「ボタンは正常に反応しています」へ変わることを確認
4. 「更新前クイックバックアップ」を押す
5. 共有画面で「ファイルに保存」を選択
