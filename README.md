# TsumManager 8.2.1 Stable

画像一括登録で毎回すべての画像を選んでも、登録済み画像を再処理しないよう改善した安定版です。

## 一括画像登録の改善

- 完全一致したツムに画像が既にある場合は自動スキップ
- スキップした画像は読込・圧縮・再保存しない
- 大量選択時の処理時間、メモリ使用量、発熱を軽減
- 新規登録件数を表示
- 更新件数を表示
- 登録済みのためスキップした件数を表示
- 候補選択待ち件数を表示
- 読込失敗件数を表示

## 画像を差し替える場合

設定の「画像の一括登録」で、

「登録済み画像も上書きする」

をオンにしてから画像を選択してください。

通常はオフのままで使用してください。
毎回すべての画像を選択しても、新しく追加した画像だけが処理されます。

## 保存設計

Ver.8.2 Stableの設計を維持しています。

- 所持数・スキル進捗・メモ：固定保存領域
- 画像：IndexedDB
- マスターデータと個人データを分離
- GitHub更新時も同じ保存領域を使用

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubへ上書きしてCommit changesを押してください。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md
