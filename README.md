# TsumManager 8.1.1 UI Fix

Ver.8.1で画像を登録しても再起動後に表示されない問題を修正したバージョンです。

## 原因

設定画面から削除した次の処理がJavaScript側に残っていました。

- コンパクト表示
- 操作取り消し履歴の削除ボタン

存在しない画面部品を操作しようとして起動処理が停止し、IndexedDBから画像を読み戻す処理まで実行されていませんでした。

## 修正内容

- コンパクト表示の残存処理を完全削除
- 操作取り消し履歴ボタンの残存処理を削除
- 起動時のJavaScript停止を修正
- IndexedDBから画像をID・名前・旧名称で読み込み
- 画像読込後に一覧を再描画
- 画像移行が確認できるまで旧保存データを削除しない
- 設定に「保存済み画像を再読み込み」を追加
- 所持数・スキル進捗・メモの固定保存を維持

## 更新後の確認

1. GitHubを更新
2. iPhoneでアプリを開く
3. 数秒待つ
4. 画像が戻らない場合は「設定」→「保存済み画像を再読み込み」
5. 画像を1体登録し、Safariを閉じて再度開いて確認

## GitHubへの更新方法

ZIPを展開し、8ファイルをGitHubへ上書きしてCommit changesを押してください。
