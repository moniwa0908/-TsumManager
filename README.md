# TsumManager 6.0

TsumManager 5.3までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 6.0の主な改善

- 設定画面から複数画像を一括登録
- ファイル名とツム名の完全一致・空白差・一意の部分一致に対応
- 一括登録結果を成功・名前不一致・読込失敗に分けて表示
- 登場年月・シリーズの専用管理画面
- 年月・シリーズCSVの書き出し／読み込み
- 登場年月未登録・シリーズ未登録だけを一覧表示
- 未登録一覧から年月とシリーズを直接入力
- シリーズによる絞り込み
- シリーズ順の並び替え
- Ver.1〜TsumManager 5.3の保存データを自動引継ぎ

## 画像一括登録

設定画面の「画像の一括登録」から利用できます。

画像ファイル名をツム名と同じにしてください。

- ミッキー.jpg
- エルサ.png
- ジェダイルーク.webp

## 登場年月データ

同梱マスターデータの登場年月登録済みは **166/646体** です。
未確認の年月を推測で埋めず、CSV取込と未登録一覧から安全に追記できる設計にしています。

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
