# TsumManager 7.0 Rescue

実際のLINE：ディズニー ツムツム画面に近いスキル入力・表示へ変更したバージョンです。
過去の保存領域から入力内容が最も多いデータを探す復旧機能も維持しています。

## 7.0の追加内容

- 一覧を「スキル3/6 25%」形式で表示
- ツムごとの最大スキルレベルに対応
- 編集画面で「スキルレベル」と「ゲージ％」を選択
- 選択内容から現在数を自動換算
- 現在数を直接入力した場合もスキル表示へ自動変換
- 詳細画面に次のスキルまであと何体か表示
- スキルゲージを現在レベル内の進捗として表示
- スキルマ必要総数ではなく、各レベル間の必要数で計算
- 過去の画像・所持数・お気に入り・メモを自動復旧
- 新しい大容量保存キーを増やさない安全設計

## スキル成長データ

- 収録ツム：751体
- 個別に確認した特殊・旧ツム：101体
- それ以外はGame8の必要総数を基にした標準プロフィールを使用
- 推定プロフィールのツムは一覧に「推定配分」と表示

## 入力例

ゲーム画面が

`スキル 3/6　25%`

の場合、編集画面で

- スキル：3/6
- ゲージ：25%

を選択してください。現在数は自動で換算されます。

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubへ上書きしてCommit changesを押してください。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
