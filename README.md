# TsumManager 5.2

TsumManager 5.1までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 5.2の追加機能

- 各ツムに登場年月データを追加
- リリース順（古い順・新しい順）を年月単位で並び替え
- 登場年フィルター
- 登場月フィルター
- 一覧カードに登場年月を表示
- ツム編集画面から登場年月を個別修正
- 設定画面に年月登録数を表示
- 年月未登録ツムは安定した収録順を補助順として利用
- Ver.1〜TsumManager 5.1の保存データを自動引継ぎ

## 登場年月データについて

今回のファイルでは、公開されている初回登場情報と照合できた **166体** に登場年月を登録しています。
年月が未登録のツムは「登場年月未登録」と表示され、編集画面から修正できます。

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
