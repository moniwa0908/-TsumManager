# TsumManager 5.3

TsumManager 5.2.1までの保存データを自動で引き継ぐ、iPhone向けツム管理Webアプリです。

## 5.3の追加機能

- ツム編集画面の画像部分をタップして写真選択
- iPhoneのカメラから直接撮影して登録
- PCで画像をドラッグ＆ドロップ
- 複数画像の一括登録
- 画像ファイル名とツム名が一致した場合に自動登録
- 画像を正方形へ自動トリミング
- 画像を自動圧縮して保存容量を軽減
- 一括登録結果として成功・名前不一致・失敗件数を表示
- Ver.1〜TsumManager 5.2.1の保存データを自動引継ぎ
- 646体図鑑、登場年月、リリース順、育成管理などを維持

## 一括画像登録のファイル名

画像ファイル名をツム名と同じにしてください。

例：

- ミッキー.jpg
- エルサ.png
- ジェダイルーク.webp

## GitHubへの更新方法

ZIPを展開し、次の8ファイルをGitHubリポジトリ直下へアップロードして上書きします。

- index.html
- style.css
- app.js
- tsums-data.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

アップロード後に `Commit changes` を押してください。
